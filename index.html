INTRODUCTION / 001
SN.SVEN NICHOLO F. ROQUE / PROFILE

Hey, I'm Sven Nicholo F. Roque — a student, guitar player, and music enthusiast. Music is more than a playlist; it's a way to express ideas, moods, and stories that are sometimes difficult to put into words.

This portfolio brings together my interests, school lab activities, and creative experiments. The design takes inspiration from underground gig posters, vinyl sleeves, and the timeless contrast of black and white.

JAVA / 2D ARRAYS & LOOPSCOMPLETED

Matrix Calculator

A Java program that accepts nine numbers in a 3×3 matrix, displays the grid, and calculates the sum of every row, column, and both diagonals. It also lets the user run the program again.
